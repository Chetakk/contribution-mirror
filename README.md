# contribution-mirror

Most of my day-to-day work happens on my company GitHub account, so those contributions don't show up on this profile. That work is confidential, so I can't share the code, the projects or any details about them.

This repo mirrors that activity here: one empty commit for each contribution on the work account, dated to the day it happened. It holds no code, repository names or commit messages, only dates and counts. A small script runs every night to keep it in sync.

So the green squares on [my profile](https://github.com/Chetakk) reflect when I'm actually working, not just my personal projects.
